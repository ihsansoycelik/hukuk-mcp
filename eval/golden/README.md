## Routing metric conventions

- `tur: normal` / `sure`: top-1 ∈ `dogru`; top-3 contains any `dogru` id.
  Time-barred (`sure`) rows still have a correct branch — limitation is the rules
  engine's job, not the router's.
- `tur: iki`: two correct nodes; top-1 ∈ `dogru`; top-3 must contain **all**
  `dogru` ids (strict).
- `tur: od`: `dogru: []`; success is `dugumAraDetay(...).belirsiz === true`,
  reported separately as "Kapsam dışı tuzak". Out-of-domain rows do not enter
  top-1/top-3 denominators.

## Search metric conventions

- Recall@5 = `|ilgili ∩ top5| / |ilgili|`, with `|ilgili| ≤ 4`.
- Precision@5 = `|ilgili ∩ top5| / min(5, |dönen|)`; an honest empty result
  scores 0, not 1.
- nDCG@10 / MRR use binary relevance.
- Citation integrity checks every returned id and every judged id resolves via
  `Corpus.kararGetir`; bozma/OR hits must never be marked `temsilci_uygun`.
